Decentralized Feature Models

Feature models describe every way a software system can vary — which options exist, which go together, which exclude each other. Most tools assume there is exactly one such model for a whole system. This site is about what happens once that stops being true: once different teams, repositories, and subsystems each own a piece of the variability, and nobody holds the whole picture at once.

It walks through three real shapes this takes — a phone split by hardware subsystem, a microservice webshop, and an open-source distribution — and lets you configure each one and watch what a decentralized resolver does when a piece is missing.
